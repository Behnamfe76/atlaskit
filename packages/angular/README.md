# @atlaskit/angular

Planned future AtlasKit Angular adapter. This package is reserved for the
shared behavior contract defined by the Vue reference adapter.

## Blueprint

- Reference adapter: `@atlaskit/vue`
- Contract: `shared-adapter-behavior`
- Required surfaces: `AtlasResourceTable`, `AtlasResourceForm`,
  `AtlasResourceShow`, `AtlasFieldRenderer`, `AtlasActionRunner`
- Required helpers: `useAtlasResource`, `useResourceTable`, `useResourceForm`,
  `useResourceShow`, `useFieldRenderer`, `useActionRunner`, `useAtlasTheme`
